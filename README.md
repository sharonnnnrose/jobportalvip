# AI Job Portal

An AI-powered job portal developed using Python and Flask to simplify the job search and recruitment process. The platform helps job seekers build resumes, analyze resume content, find relevant job opportunities, and explore available jobs.

## Features

- **Resume Builder:** Create professional resumes using user-provided details.
- **AI Resume Analyzer:** Analyze uploaded resumes and identify relevant skills.
- **AI Job Matching:** Match resumes with suitable job opportunities using similarity-based matching.
- **Browse Jobs:** Explore available job listings.
- **Add Jobs:** Add new job opportunities to the portal.
- **User-Friendly Interface:** Simple and easy-to-use web interface.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd AI-Job-Portal
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

```text
http://127.0.0.1:5000
```
